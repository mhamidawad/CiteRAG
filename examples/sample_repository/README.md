# Sample repository for offline CiteRAG tests

This synthetic Python example contains no private user data. It demonstrates a simple function and associated explanation. CiteRAG currently indexes approved Markdown/text documents, not arbitrary source trees by default; copy approved descriptions under `docs/` or implement a tested source loader before claiming code-file ingestion.

Function: `normalize_name` removes surrounding whitespace and lowercases a name. An unsupported claim about database credentials has no evidence in this sample.
